# BlogVerse

A full-stack blog website built with React, Node.js, Express.js and MongoDB.

## 🚀 Live Demo

https://blogverse-beige.vercel.app/

## 🔗 Backend API

https://blogverse-beige.vercel.app

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Git & GitHub
- Vercel
- Render

## ✨ Features

- User Signup & Login
- JWT Authentication
- Logout
- Blog Listing
- Course Listing
- Responsive Design
- Mobile Responsive Navbar
